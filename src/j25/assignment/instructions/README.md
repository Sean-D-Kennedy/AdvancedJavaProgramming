# Java 25 Assignment (Course Practice)

## How to do this assignment
1. Start with the **instructions** in `src/j25/assignment/instructions/`.
2. Follow the files in order: `01-...`, `02-...`, `03-...`, etc.
3. Create the Java files from scratch by copy/pasting the code blocks from each step.
4. Run frequently after each part.
> Note: IntelliJ only creates Run configurations for files with an entry point (`main`).
> `LecturerCsvLoader` is a utility class (no `main`), so it cannot be run directly.
> Run `RunLecturerCsvLoader` to test your work.

## If you get stuck
- The repository contains a working end-state (the “solution”).
- Compare your files with the final versions in `src/j25/assignment/`.
